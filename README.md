# 清屏（QingPing）Android V1.0 源码

这是一个原生 Android Studio 项目起点，包含毛玻璃风格首页、本地事件统计、无障碍服务和开机广播记录。

## 当前版本实际具备
- 原生 Kotlin + Jetpack Compose UI。
- 引导用户进入系统无障碍设置。
- 无障碍服务监听可访问的窗口事件。
- 仅对完全匹配的明确跳过标签尝试点击：`跳过广告`、`Skip Ad` 等。
- 本地保存最近 500 条事件，统计检测、干预和系统接受点击操作的次数。
- 接收开机广播并记录提示，不尝试绕过 Android 后台启动限制。

## 重要限制
- “系统接受点击操作”不等于广告一定消失，所以 UI 中的“确认”只代表点击动作被接受，尚不代表广告被可靠验证为已拦截。正式版本应改名为“点击已执行”，并通过后续窗口状态验证后再记为“确认拦截”。
- 该版本是开发源码，不是已签名 APK；此环境未提供 Android SDK/Gradle 构建环境，未在真机编译验证。
- 部分广告没有可访问节点，或使用图片/视频/自绘控件，无法通过此方案识别。
- 不保证后台永不被系统或厂商省电策略停止。
- 无障碍权限非常敏感，用户必须主动启用；请只在自己信任的设备上测试。
- Android 13+ 通知权限可能需要在后续加入前台服务时请求。
- 目前尚未实现真正的前台服务、悬浮窗、可配置应用白名单、跨设备规则库和可靠的“广告消失”验证。

## 构建方法
1. 安装 Android Studio（建议较新稳定版）。
2. 打开本目录。
3. 使用 JDK 17 或 Android Studio 内置 JDK。
4. 等待 Gradle 同步完成并安装 Android SDK Platform 35。
5. 连接安卓设备或启动模拟器，点击 Run。
6. 首次打开后点击“去开启”，在系统设置中手动启用“清屏广告检测服务”。
7. 返回清屏，观察本地事件记录。

## 下一步建议
- 增加基于事件后窗口变化的“结果验证”，将“点击动作成功”与“广告确实消失”分开。
- 按应用启用/停用规则，避免在未知页面自动操作。
- 添加前台服务通知与品牌定制后台设置引导。
- 在多款目标设备上测试后再考虑发布 APK。
